# 日本二手房市场 — SUUMO + at home 中古公寓跨站比价

**日本最大级不动产门户 SUUMO 与 at home 的东京 23 区中古公寓（二手房）售价跨站比较。相同车站·相同户型的房价一目了然。**本 Actor 聚合两大门户的挂牌信息，针对相同车站与相同户型进行横向价格对比，帮助投资者、购房者与研究者在移居日本或投资前掌握真实房价行情。

> 🇯🇵 English: [Japan Property Market](https://apify.com/fruitful_quintessence) ｜ 🇰🇷 한국어: Japan Property Market (KR)

## 功能亮点

- 跨站比价：同一车站·同一户型的公寓，SUUMO 与 at home 的价格差异一目了然
- 车站聚焦：`北参道`、`渋谷`、`新宿` 等热门车站的房价趋势可单独追踪
- 结构化输出：售价、地址、最近车站与步行时间、户型/布局、面积（㎡）、来源网站、所在行政区等字段完整
- 灵活来源：默认同时抓取 SUUMO 与 at home，也可只抓取其一
- 按次计费：仅按实际抓取条数计费，无月租捆绑

## 输入

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `ward` | select | `渋谷区` | 东京23区（千代田区/港区/新宿区/渋谷区/世田谷区等） |
| `maxItems` | integer | 100 | 最大获取件数 |
| `maxPages` | integer | 2 | 每个来源的最大页数 |
| `sources` | string | `suumo,athome` | 数据来源 |
| `searchKeyword` | string | （可选） | 按车站或关键词过滤 |

## 使用场景

- **投资分析**：追踪东京 23 区公寓的价格走势与区域差异
- **跨网站比较**：发现同一房产在不同门户的价格差，抓住性价比机会
- **购房规划**：移居日本前，按目标车站与区域掌握真实行情
- **市场研究**：批量采集挂牌数据，用于 Rent/Sale 价格指数与供需分析
- **AI 训练数据**：为房产价格预测、区域特征分类模型构建标注数据集
